About this Website

This website was created as a Web Development project for IT 240 Web Fluency. It is designed as a Pokémon Generation 4 Pokédex interface used to demonstrate HTML, CSS, and JavaScript skills.

The goal of this project is to show my ability to build a multi-page interactive website with consistent design, animations, and user interaction features.

Technical Skills Used

  • HTML5 structure and multi-page navigation
  • CSS styling
  • JavaScript interactivity

Project Highlights

  • Interactive starter Pokémon selection system
  • Legendary and Mythical Pokémon toggle interface
  • Custom UI styling inspired by Pokémon Diamond & Pearl menus
  • Animated glow effects and themed card layouts

Project Purpose

This project demonstrates front-end web development skills and UI design principles. It also shows creativity in building a themed user experience while following structured web development practices.
